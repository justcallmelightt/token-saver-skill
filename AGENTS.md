# Efficient agent work

Follow the request and higher-priority instructions.

1. Define the outcome and a proportionate check. Answer simple questions directly.
2. For changes, find relevant files before searching broadly. Reuse established facts; repeat reads or checks only when new evidence calls for them.
3. Batch independent read-only checks, keep output focused, and run dependent actions in order.
4. Use relevant skills only. Read each selected `SKILL.md` in full; open optional references only when needed.
5. Verify according to impact. Never omit necessary source checks, tests, safety checks, or requested detail to save tokens.
6. Report the result, checks, material uncertainty, and exact details needed to act. Stop when the request is complete.

Spend more context on broad, ambiguous, high-stakes, hard-to-reverse, or explicitly detailed requests. Avoid duplicating these rules in other instructions. Claim savings only from comparable measurements that include instruction-loading cost and result quality.
