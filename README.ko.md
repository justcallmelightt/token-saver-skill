# Token Saver Skill

정확성을 희생하지 않으면서 불필요한 맥락 수집, 반복 도구 작업, 지나치게 긴 답변을 줄이기 위한 Agent Skill입니다.

## 이 Skill이 하는 일과 하지 않는 일

[`token-saver/SKILL.md`](token-saver/SKILL.md)는 작업 중 불필요한 토큰 사용을 줄이도록 돕는 가벼운 작업 지침입니다. 모델의 토크나이저를 바꾸거나 API 비용 절감을 보장하지 않으며, 플랫폼 내부의 추론이나 도구 처리에 쓰이는 토큰까지 줄이지는 않습니다. Skill 자체를 불러오는 비용 때문에 짧은 작업에서는 오히려 이득이 없을 수 있습니다.

핵심 원칙은 분명합니다. 필요한 소스 확인, 테스트, 안전 점검, 사용자가 요청한 세부사항을 생략해서 토큰을 아끼지 않습니다. 복잡하거나 중요한 작업은 더 많은 토큰을 써야 올바르게 처리할 수 있습니다.

## 구성

- [`token-saver/SKILL.md`](token-saver/SKILL.md) — 여러 Agent Skills 호환 환경에서 사용할 수 있는 핵심 지침입니다.
- [`token-saver/agents/openai.yaml`](token-saver/agents/openai.yaml) — 선택 사항인 OpenAI/Codex UI 메타데이터입니다. 핵심 Skill은 이 파일에 의존하지 않습니다.

## 설치 및 사용

Agent Skills를 지원하는 클라이언트에서 `token-saver/` 폴더를 Skill 폴더로 사용하세요. Skill 설치 기능이 있는 클라이언트에서는 이 저장소의 `token-saver`를 선택하고, 그렇지 않다면 해당 클라이언트의 공식 안내에 따라 폴더를 복사하면 됩니다. 폴더 이름과 frontmatter의 `name`은 `token-saver`로 유지하세요.

이 저장소는 초기 검토를 위해 비공개로 운영 중입니다. 아직 공개 배포하지 않았으며, 측정된 절감률도 주장하지 않습니다.

## 효과 검증 방법

동일한 모델과 설정으로 대표 작업을 Skill 사용 전후에 비교하세요.

1. 도구를 쓰지 않아도 되는 간단한 사실 질문
2. 관련 파일 하나를 확인하고 집중 테스트가 필요한 작은 코드 변경
3. 특정 오류나 결과만 찾으면 되는 긴 도구 출력
4. 필요한 세부사항과 검증을 줄이면 안 되는 범위가 넓거나 중요한 요청

가능하다면 입력 토큰과 출력 토큰을 따로 기록하고, 도구 호출 수와 소요 시간도 함께 적으세요. 결과가 요청에 맞게 정확하고 완전한지도 평가해야 합니다. Skill 지침 자체의 토큰 비용도 포함하세요. 대화가 짧아 보인다는 이유만으로 토큰 절감을 단정하지 마세요.

## 피드백

이 지침이 실제로 AI의 작업 방식을 바꾸는지, 지나치게 압축하거나 불필요한 절차를 추가하는 부분은 없는지, 검증 사례가 실제 작업을 잘 반영하는지 의견을 주세요. 근거 없는 절감률 대신 관찰 결과를 바탕으로 다음 버전을 개선하려 합니다.
