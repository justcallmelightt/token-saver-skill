# AGENTS.md

Token Saver는 필요한 검증은 유지하면서 불필요한 맥락 수집, 반복 도구 작업, 지나치게 긴 답변을 줄이기 위한 짧은 [`AGENTS.md`](AGENTS.md) 템플릿입니다.

## 프로젝트에서 사용하기

이 저장소의 [`AGENTS.md`](AGENTS.md) 내용을 적용할 프로젝트의 루트 `AGENTS.md`에 추가하세요. 기존 파일이 있다면 덮어쓰지 말고 기존 프로젝트 지침을 유지한 채 내용을 합치세요. 사용하기 전에 충돌하는 지침이 없는지 확인하세요.

`AGENTS.md`를 읽는 에이전트는 이 저장소 안에서 작업할 때 이 파일을 적용합니다. 다른 프로젝트에서 링크만 걸어두면 그곳의 에이전트가 자동으로 읽는 것은 아니므로, 실제 작업할 프로젝트에 지침을 넣어야 합니다.

## 지침의 역할

- 요청한 결과와 그 결과를 확인할 적절한 방법부터 정합니다.
- 관련 파일을 먼저 찾고, 현재 작업에서 이미 확인한 정보를 재사용합니다.
- 답을 바꿀 수 없는 반복 도구 호출과 과도한 출력을 줄입니다.
- 작업에 맞는 전문 Skill을 선택하고, 관련 없는 Skill을 불러오지 않도록 돕습니다.
- 필요한 소스 확인, 테스트, 안전 점검, 사용자가 요청한 세부사항은 유지합니다.

이는 작업 지침이며 모델의 행동이나 API 비용을 보장하지 않습니다. 토크나이저를 바꾸거나 플랫폼 내부 작업을 제어할 수 없습니다. 특히 짧은 작업에서는 지침 자체의 토큰 비용이 더 클 수도 있습니다.

## 효과 검증

같은 모델, 설정, 환경에서 지침을 적용한 경우와 적용하지 않은 경우를 비교하세요. 간단한 질문, 작은 코드 변경, 긴 도구 출력이 있는 작업, 범위가 넓거나 중요한 요청을 포함하면 좋습니다. 결과의 품질과 완전성을 입력·출력 토큰, 도구 호출 수, 소요 시간과 함께 기록하세요. 측정할 수 있다면 지침을 불러오는 비용도 포함해야 합니다. 대화 길이만 보고 절감률을 주장하지 마세요.
