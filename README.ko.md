# AGENTS.md

Token Saver는 필요한 검증은 유지하면서 불필요한 맥락 수집, 반복 도구 작업, 지나치게 긴 답변을 줄이기 위한 짧은 [`AGENTS.md`](AGENTS.md) 템플릿입니다.

## 프로젝트에서 사용하기

이 저장소의 [`AGENTS.md`](AGENTS.md) 내용을 적용할 프로젝트의 루트 `AGENTS.md`에 추가하세요. 기존 파일이 있다면 덮어쓰지 말고 기존 프로젝트 지침을 유지한 채 내용을 합치세요. 사용하기 전에 충돌하는 지침이 없는지 확인하세요.

`AGENTS.md`를 읽는 에이전트는 이 저장소 안에서 작업할 때 이 파일을 적용합니다. 다른 프로젝트에서 링크만 걸어두면 그곳의 에이전트가 자동으로 읽는 것은 아니므로, 실제 작업할 프로젝트에 지침을 넣어야 합니다.

매 작업에 적용되는 지침은 짧게 유지하세요. 작업별 절차는 Skill에 두고, `SKILL.md` 본문은 간결하게 작성하며 선택 사항인 세부 자료는 별도로 분리하세요. 선택한 `SKILL.md`는 클라이언트의 읽기 규칙에 따라 전체를 확인해야 합니다.

## 지침 자체의 부담을 줄이는 설계

이 저장소에는 간결한 `AGENTS.md` 하나만 있으며, `SKILL.md`는 없습니다. 지침은 관련 있는 맥락만 확인하고, 반복 도구 작업을 피하며, 작업에 맞는 설치된 전문 Skill만 선택하도록 설계했습니다. 선택한 Skill의 필수 지침은 모두 읽고, 선택 자료는 필요할 때만 불러옵니다. 같은 규칙을 여러 지침 파일에 반복하지 않도록 했습니다.

이것이 지침 자체의 부담까지 고려해 불필요한 토큰 사용을 줄이도록 설계한 방식입니다. 실제 총 토큰이나 청구 비용 절감은 보장하지 않으며, 짧은 작업에서는 지침을 읽는 비용이 더 클 수도 있습니다.

## 효과 검증

같은 모델, 설정, 환경에서 지침을 적용한 경우와 적용하지 않은 경우를 비교하세요. 간단한 질문, 작은 코드 변경, 긴 도구 출력이 있는 작업, 범위가 넓거나 중요한 요청을 포함하면 좋습니다. 결과의 품질과 완전성을 입력·출력 토큰, 도구 호출 수, 소요 시간과 함께 기록하세요. 측정할 수 있다면 `AGENTS.md`, 선택한 `SKILL.md`, 참고 자료를 불러오는 비용도 포함해야 합니다. 대화 길이만 보고 절감률을 주장하지 마세요.
